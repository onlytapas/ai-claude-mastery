Sources and accuracy

Each chapter lists its own sources at the end. This page explains how facts in the book are checked and lists the main sources used throughout.

How facts are checked

Kind of factHow it's checkedHow often it changes
History, research papers, how the technology worksOriginal papers and authoritative historiesRarely
Company facts (founding, founders, products)The company's own pages and announcementsYearly
Model names, release dates, prices, limitsOfficial model and pricing pages, with a "last verified" dateMonthly
Claude app features and plansAnthropic's product pages and help centreMonthly
Claude Code commands, flags and settingsAnthropic's Claude Code documentation and the installed version's own help outputWeekly

Main sources

  • Anthropic: company news and research at anthropic.com; developer documentation at docs.claude.com; Claude Code documentation at code.claude.com/docs; help centre at support.claude.com.
  • Claude Code 2.1.319: the installed program's claude --help output, captured on 9 November 2026.
  • Other AI companies: official sites and documentation of OpenAI, Google DeepMind, Microsoft, Meta, NVIDIA, Amazon Web Services, xAI, DeepSeek, Mistral AI and Alibaba Cloud, cited chapter by chapter.
  • Research papers: original papers, linked from the chapter where they're discussed (for example Turing 1950, Vaswani et al. 2017, Bai et al. 2022).

If you find a mistake

Treat this book like any system under test. If something here doesn't match what you see, trust the official source and your own installed version, and note the difference. Version numbers and dates at the end of each chapter tell you how old the information is.
