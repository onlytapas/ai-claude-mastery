In everyday life

Publishing the Transformer was a bit like a carmaker publishing the design of a new engine. Rivals, including OpenAI, built on it. Google gained reputation and talent, and the whole field moved faster, but it also handed competitors a head start.

How a Mixture of Experts works, without maths

A normal ("dense") model uses all of its parameters for every token it reads or writes. A Mixture-of-Experts (MoE) model splits parts of the network into many smaller sub-networks called experts. A small "router" looks at each token and sends it to only a few experts. The rest stay idle for that token.

That is why you see two numbers in model announcements. Microsoft describes MAI-Thinking-1 as about 1 trillion total parameters but only about 35 billion active per token. The total size gives the model lots of knowledge capacity. The active size decides how much computing each token costs. You still need enough memory to hold all the experts, so MoE models are cheap to run per token but not small to host.

The idea is older than 2017, but the 2017 Google Brain paper by Shazeer and colleagues (arXiv 1701.06538) showed how to make it work at very large scale.

28.7Microsoft and OpenAI: a partnership rewritten

For most people, "Microsoft AI" meant "OpenAI inside Microsoft products". The relationship is the most important partnership in the industry, and it has changed shape several times.

  1. 2019First investment. Microsoft invests in OpenAI; Azure becomes OpenAI's cloud.
  2. 2023Billions more. After ChatGPT, Microsoft puts much larger sums into OpenAI and builds GPT models into Bing and Copilot.
  3. Oct 2025Recapitalisation. OpenAI's for-profit arm becomes OpenAI Group PBC, controlled by the OpenAI Foundation. Microsoft receives a stake of about 27%.
  4. Apr 2026Deal rewritten (27 April): Microsoft's licence to OpenAI's technology becomes non-exclusive, through 2032. OpenAI may serve its products on any cloud, though Azure stays primary and gets launches first. The "AGI clause" is removed. OpenAI keeps paying a 20% revenue share, now capped, through 2030.

What Microsoft gets

A large ownership stake, a licence to OpenAI technology until 2032, revenue share until 2030, and first launches on Azure.

What OpenAI gets

Freedom to use other clouds (it has deals with Oracle, AWS and others), and no longer has to worry about the AGI clause.

What was the "AGI clause"?

Earlier versions of the agreement were widely reported to say that Microsoft's rights to OpenAI's technology would change once OpenAI's board declared it had reached artificial general intelligence. Because nobody agrees on how to define AGI, this made the contract's future uncertain for both sides. The April 2026 amendment removed it, so the deal now runs on fixed dates (2030 and 2032) instead.

The lesson for readers: big AI partnerships are contracts with end dates and conditions, not permanent marriages. When a vendor says "we use model X", ask how long that arrangement is guaranteed.

Opinion · industry analysts

Many analysts read Microsoft's MAI models and its Anthropic deal as hedging: if the OpenAI partnership weakens, Microsoft still has models to put in Copilot. Microsoft presents it as offering customers choice. Both readings fit the facts; neither is proven.

hub_top.py (Python 3, standard library only)
"""List the most-downloaded public models for each organisation on the Hugging Face Hub."""
import json
import sys
import urllib.parse
import urllib.request

API = "https://huggingface.co/api/models"


def top_models(author, limit=5):
    query = urllib.parse.urlencode({"author": author, "sort": "downloads", "limit": limit})
    with urllib.request.urlopen(f"{API}?{query}", timeout=20) as resp:
        return json.load(resp)


def licence_of(model):
    for tag in model.get("tags", []):
        if tag.startswith("license:"):
            return tag.split(":", 1)[1]
    return "(not stated)"


def main():
    authors = sys.argv[1:] or ["google", "microsoft"]
    for author in authors:
        print(f"\n== {author} ==")
        models = top_models(author)
        if not models:
            print("  no public models found (check the spelling)")
        for m in models:
            print(f"  {m['id']:<50} {m.get('downloads', 0):>12,}  {licence_of(m)}")


if __name__ == "__main__":
    main()

Troubleshooting
  • CERTIFICATE_VERIFY_FAILED on a Mac: the Python from python.org needs its certificates installed once. Run Install Certificates.command from your /Applications/Python 3.x/ folder, then try again.
  • Timeout or connection refused at work: your company network may block the site. Try from home, or simply open https://huggingface.co/google and https://huggingface.co/microsoft in a browser and sort by downloads.
  • python3: command not found on Windows: try py hub_top.py instead.
  • "no public models found": organisation names are case-sensitive on the Hub; check the spelling in the page address.
Common misunderstandings
"Gemma is just a free version of Gemini."
Gemma is a separate open-weight family you can download and run yourself. Gemini is proprietary and only available as a service. They share research, but they are different models with different sizes and licences.
"Microsoft owns OpenAI."
Microsoft holds a stake of about 27% in OpenAI Group PBC, which is controlled by the nonprofit OpenAI Foundation. Since April 2026 its licence to OpenAI technology is non-exclusive.
"Copilot means GPT."
Copilot is a brand for Microsoft's AI features. Behind it Microsoft can use OpenAI models, its own MAI models, and in some products third-party models. Check which model a particular Copilot feature uses.
"If my company uses Microsoft or Google, I can't use Claude."
Both Microsoft Foundry and Google Cloud offer Claude models, so a company can often enable Claude inside the cloud contract it already has.
"Gemini CLI is gone."
It was retired for free and individual users in June 2026 and replaced by Antigravity CLI. It still works with paid API keys.
