Claude isn't only a website. The same account works in a desktop app for Mac, Windows and (in beta) Linux, in phone apps, as a Chrome extension that can click and type in web pages, inside Excel, PowerPoint, Word and Outlook, and in Slack. Each place suits different work: desktop for quick questions and local tools, mobile for voice and on-the-go checks, Chrome for web tasks, Office for documents, Slack for team threads. Features and plan rules differ between them, and they change often, so this chapter dates every interface detail. It ends with sharing and exporting, which work the same wherever you started.

Real-world example: faster bug reports

A tester spots a misaligned error message in a staging build. She double-taps Option, drags over the broken area, and types: "Write a bug report for this. Thirty seconds later she has a draft to paste into Jira, with the screenshot already described. She still checks the steps herself, because Claude can only see the picture, not how she got there. (Chapter 46 covers screenshots and privacy.)

Screens show more than you think

A screenshot can include customer names, tokens in a URL bar, or a chat window in the corner. Crop to the area that matters, and use test data on test environments.

51.3The mobile apps

The iOS and Android apps carry your chats, projects and connectors with you. They're strongest at short tasks and voice.

  • Photos and files: photograph a device screen, a whiteboard of test ideas or an error on a kiosk, and ask about it.
  • Voice mode and dictation: covered in section 51.6; voice mode is designed mainly for phones.
  • Phone integrations: Anthropic's help center documents iOS features such as working with system apps, Shortcuts and widgets, and an Android widget. Availability varies by country, plan and device; check the mobile collection in the help center for your platform.
Mobile limits worth knowing

Research on mobile searches only the web and silently skips connectors (Chapter 49). The per-chat memory switch locks after the first message (Chapter 50). Data export can't be started from the mobile apps. Installing new connectors on mobile is in beta, so add them on the web or desktop first.

51.4Claude in Chrome

Claude in Chrome is a browser extension that lets Claude read, click and navigate websites with you. You give it a task in Chrome's side panel ("find the cheapest plan on this pricing page and fill in the sign-up form with my test details") and it works through the page step by step. It can also be started from Claude Cowork or Claude Code.

  • Plans: paid plans only. Anthropic launched it as an experiment in August 2025 and made it a beta for all paid plans in December 2025.
  • Browser: Google Chrome only, installed from the Chrome Web Store with Add to Chrome. Pin it from the puzzle-piece menu.
  • Permissions: it asks for powerful browser permissions, including debugger (to click, type and take screenshots), scripting (to read page text), tabs and tabGroups, and webNavigation.
  • Modes: as of 9 November 2026 the side panel starts in Automatically approve mode, where Claude keeps working, checks each action and pauses when it needs your approval. A mode you choose is kept for future sessions.
  • Shortcuts and schedules: you can save prompts as shortcuts (run them by typing /), record a workflow for Claude to repeat, and schedule tasks daily, weekly, monthly or yearly while Chrome is open.
  • Admin controls: on Team and Enterprise, admins control whether the extension is allowed and can set site allowlists and blocklists.
Anthropic's own words: "still risky"

Anthropic's help page says the extension uses safety classifiers but is "still risky", and points to its safety guide. A browser agent reads web pages written by others, and any of them can contain hidden instructions (prompt injection). Because the extension can act in sites where you're logged in, an injected instruction could try to send email, change settings or copy data. Use a separate Chrome profile with only test accounts, keep it away from banking, email and admin consoles, and read every approval request.

Good QA uses

  • Exploring a staging site and listing what looks broken
  • Running through a manual smoke checklist and recording results
  • Filling long test forms with varied test data
  • Checking that links on a release page all resolve

Better done another way

  • Regression checks you'll repeat: write Playwright tests (Chapter 102)
  • Anything in production with real customer data
  • Exploration inside Claude Code: Playwright MCP gives you more control
  • Pass/fail evidence for an audit: use scripted tests with reports

51.6Voice: voice mode and dictation

Two features use your voice, and they're different:

Dictation

Speech-to-text. You speak, it becomes text in the message box, you review and send. Available in the apps, in Quick Entry on Mac, in Cowork and Claude Code, and in the Office add-ins.

Voice mode (beta)

A spoken, two-way conversation: you talk, Claude answers aloud. All plans, on iOS, Android, desktop and web. You can switch between voice and text in the same chat.

How to start voice mode (as of 9 November 2026): on web and desktop, start a new chat and select the sound-wave icon at the lower right; select Stop to finish. On mobile, tap the sound-wave icon next to the microphone and pick a voice.

  • Hands-free (default): Claude listens and replies when you pause. Best somewhere quiet.
  • Push-to-talk: hold a button while you speak. Better in noisy places.
  • Tools: in voice mode Claude can use connected tools such as Gmail, Google Calendar, Google Docs and Slack.
  • Limits: voice counts toward your usage limits; Anthropic notes Claude Fable isn't available in voice mode; non-English languages are in beta. Voice mode isn't available in Cowork or Claude Code (dictation is).
Real-world example

On the way to work, a test lead uses voice mode: "Ask me questions to help plan exploratory testing for the new loyalty-points feature." Claude asks about risks, users and integrations, and she answers out loud. At her desk, the chat holds the whole conversation as text, ready to turn into test charters.

51.7Sharing and exporting

Sharing a chat

Select Share at the upper right of a chat, then Share again in the pop-out to create a link (as of 9 November 2026). The link points to a snapshot:

  • It includes the messages sent before you shared, and any artifacts. Later messages stay private unless you unshare and share again, which updates the snapshot.
  • Attached files are not included. Raw data from connector (MCP) tool calls is hidden; viewers see only the conversation and final output.
  • On Free, Pro, Max and Ultra, anyone with the link can view it. Team and Enterprise users can share only with people in their organisation, and Owners can stop chats that used connectors from being shared at all.

To unshare, open the Share menu and change the visibility from Public to Private. To review everything you've shared (Free, Pro, Max and Ultra), go to Settings > Privacy and select Manage next to Shared chats, then Unshare any you no longer want public.

A public link is public

Anyone who gets the link can read it, including people it was forwarded to. Before sharing a chat from a personal account, read it top to bottom for internal URLs, names, ticket numbers or logs. For work, a Team or Enterprise account keeps shares inside the organisation.

Exporting your data

Go to Settings > Privacy on the web or desktop app (not mobile) and select Export data. A download link arrives by email at your account's address after a short wait.

  • The export includes chats, projects, memory and account data. It doesn't include the original files you uploaded.
  • The link needs you to be signed in, expires 24 hours after it's created, and may work only once, so download it straight away.
  • On Team and Enterprise, members can export only their own chats, and only if an Owner has turned on Allow members to export their own data. Primary Owners export the whole organisation from Organization settings > Data and privacy.

Troubleshooting: Quick Entry does nothing: the desktop app must be running, Accessibility permission must be granted, and macOS must be 12 or later. Common misunderstandings
"A shared link always shows the latest version of the chat."
It's a snapshot of the moment you shared. Unshare and share again to update it.
"Sharing includes the files I attached."
Attached files stay private and aren't part of the shared snapshot.
"Claude in Chrome is safe because it asks before acting."
It pauses when it judges approval is needed, but Anthropic itself calls it "still risky". Use test accounts in a separate profile.
"Voice mode and dictation are the same thing."
Dictation turns speech into text you send; voice mode is a spoken conversation where Claude answers aloud.
"The Slack connector puts Claude in Slack."
The connector lets claude.ai search Slack. Claude Tag is what puts Claude inside Slack channels.

51.8Review

Key takeaways
  • Web, desktop and mobile apps are on all plans; Chrome and the Office add-ins need a paid plan; Claude Tag is for Team and Enterprise.
  • The desktop app adds Quick Entry, screenshots and dictation on Mac, local connectors, and the Cowork and Code areas.
  • Mobile is best for quick tasks and voice; research there skips connectors, and export isn't available.
  • Claude in Chrome acts in real web pages; treat it as risky and keep it to test accounts.
  • Shared chats are snapshots without attached files; export from Settings > Privacy on web or desktop, and download within 24 hours.
  • Every UI location here is as of 9 November 2026 and is likely to change.
