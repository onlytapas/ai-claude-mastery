Claude isn't only an app. Underneath claude.ai and Claude Code is the Claude API, which any program can call. You create an API key in the Claude Console, keep it secret in an environment variable, and send an HTTP POST to https://api.anthropic.com/v1/messages with three headers and a small JSON body: which model, how long the answer may be, and the messages. Claude replies with JSON containing its answer and a count of the tokens used, which is what you pay for. Once you've done this once, you can put Claude inside test tools, scripts and pipelines.

86.1Why use the API at all?

Use the apps (claude.ai, Claude Code) when…

  • a person is in the loop, typing and reading
  • you want features like Projects, Artifacts or file editing already built
  • you're on a subscription plan

Use the API when…

  • a program needs Claude, with no person typing
  • you're building Claude into your own tool
  • you need to run the same prompt hundreds of times, such as classifying every test failure overnight
Real-world example: QA uses for the API
  • A nightly job sends each failed test's error log to Claude and posts a grouped summary to Slack.
  • A small internal web page where testers paste a user story and get draft test cases in the team's format.
  • A pipeline step that checks every new bug report has steps, expected and actual results, and asks the reporter to fill gaps.
  • An evaluation harness that sends 200 prompts to your company's chatbot and to Claude-as-judge (Chapter 125).
Separate billing

The API is billed separately from claude.ai subscriptions. A Pro, Max, Team or Enterprise chat plan doesn't include API credits, and API usage is paid per token through the Console. Your company may already have an API organisation; ask before creating your own.

86.2The Claude Console: organisations, workspaces and keys

The Claude Console at platform.claude.com is where developers manage API access. (It used to be at console.anthropic.com, which now redirects there.)

ConceptPlain meaning
OrganisationYour company's API account: billing, members, limits
WorkspaceA sub-area of the organisation that groups API keys, members and limits, such as "QA tools" or "Production chatbot". An organisation can have up to 100.
API keyA secret string that identifies your program to the API. It belongs to a workspace.
BillingBuy credits or set up invoicing; set your own spend limit (Settings → Billing)
Usage tierYour organisation's level, which sets rate limits and a monthly spend cap. It rises automatically as you build usage history.
PlaygroundA page in the Console for trying requests by hand before writing code (83.8)

Creating a key, step by step

  1. Sign in at platform.claude.com (or create an account).
  2. Make sure billing is set up, or that your organisation admin has given you access to a workspace with credits.
  3. Go to Settings → API keys (platform.claude.com/settings/keys) and create a key. Give it a descriptive name, like "qa-nightly-triage", and choose the workspace.
  4. Copy the key immediately and store it safely (next section). The Console doesn't show the full key again.
One key per purpose

Create separate keys for separate tools and people. If one leaks, you revoke just that key and everything else keeps working. Never share a key in chat, email, tickets or screenshots. Chapter 98 covers key rotation, expiry and secrets managers.

86.3Storing the key: ANTHROPIC_API_KEY

The official tools look for your key in an environment variable called ANTHROPIC_API_KEY. An environment variable is a named value your terminal keeps in memory and passes to programs you run (Chapter 56). Using one keeps the key out of your code.

macOS / Linux (zsh or bash): current terminal only
export ANTHROPIC_API_KEY="paste-your-key-here"
echo ${ANTHROPIC_API_KEY:0:12}…     # check it's set by printing only the start
Windows PowerShell: current window only
$env:ANTHROPIC_API_KEY = "paste-your-key-here"

The variable disappears when you close the terminal. To keep it, teams use a secrets manager, a password manager's command-line tool, or a .env file that is listed in .gitignore so it's never committed. In CI systems such as GitHub Actions, it goes in the platform's encrypted secrets.

Classic key leaks
Hard-coding it
client = Anthropic(api_key="sk-...") committed to git. Bots scan public repositories for keys within minutes.
Printing it in logs
Debug output or curl -v in a CI log shows the full Authorization header.
Pasting it into an AI chat
Including asking Claude Code "why doesn't my key sk-… work?". Describe the problem instead.

86.4Anatomy of a Messages API request

Everything you send to Claude goes to one endpoint: POST https://api.anthropic.com/v1/messages. Here is a complete request in curl, with every part explained below. Verified 9 Nov 2026

Your first Claude API call
curl https://api.anthropic.com/v1/messages \
  -H "content-type: application/json" \
  -H "Authorization: Bearer $ANTHROPIC_API_KEY" \
  -H "anthropic-version: 2026-10-21" \
  -d '{
    "model": "claude-opus-5-5",
    "max_tokens": 1000,
    "system": "You are a senior QA engineer. Reply concisely.",
    "messages": [
      {"role": "user", "content": "Give five boundary test values for an age field that accepts 18 to 65."}
    ]
  }'

The headers

HeaderValueRequired?Meaning
content-typeapplication/jsonYesThe body is JSON
AuthorizationBearer <your key>Yes, unless x-api-key is usedYour API key (or a short-lived access token from Anthropic's identity features)
x-api-key<your key>AlternativeThe older way to send the key. Still supported; you'll see it in many examples, including Anthropic's quick-start.
anthropic-version2026-10-21YesWhich version of the API's rules you're writing against
Why there's a version header

APIs change over time. If Anthropic changed how a field worked, every existing program would break overnight. Instead, you declare which version you were written for, and Anthropic promises not to remove or change existing inputs and outputs within that version. It may still add new optional fields and new values, so well-written code ignores fields it doesn't recognise.

The current version, 2026-10-21, is the first new one since 2023-06-01. Among other changes, it removes the temperature, top_p and top_k parameters: sending any of them now returns a 400 error. Older tutorials that set temperature will fail with this version. The official SDKs send the version header for you.

The body

FieldRequired?What it does
modelYesWhich Claude model. Current IDs: claude-fable-5-1, claude-opus-5-5, claude-sonnet-5-5, claude-haiku-5-5. Anthropic recommends starting with Opus 5.5 for most work (Chapter 40).
max_tokensYesThe most tokens Claude may produce in its reply. A safety cap on length and cost, not a target. If the answer hits it, it's cut off.
messagesYesThe conversation: a list of turns, each with a role (user or assistant) and content. For one question, it's a single user message.
systemNoThe system prompt: instructions about role, rules and format that apply to the whole conversation

There are many more optional fields: streaming, tools, effort and structured outputs. Chapters 87–90 cover them. These four are enough to start.

In everyday life

Think of the request as a form you hand to a very capable contractor. The model is which contractor you hire. max_tokens is "don't write more than ten pages". The system prompt is the standing brief ("you're working for the QA team; use our format"). The messages are the actual conversation so far.

86.5Reading the response

Claude replies with a JSON object. Here is the shape documented by Anthropic, annotated:

A Messages API response (annotated)
{
  "id": "msg_013mHbppMPd2PrVJzGMZPt2D",   ← unique ID of this reply
  "type": "message",
  "role": "assistant",                     ← it's Claude speaking
  "model": "claude-opus-5-5",              ← the model that answered
  "content": [                             ← a LIST of content blocks
    {
      "type": "text",
      "text": "1. 17 (just below minimum, should be rejected)\n2. 18 ..."
    }
  ],
  "stop_reason": "end_turn",               ← why it stopped
  "stop_sequence": null,
  "stop_details": null,
  "usage": {
    "input_tokens": 42,                    ← tokens you sent (billed as input)
    "output_tokens": 310                   ← tokens it produced (billed as output)
  }
}

Content is a list

content is a list of blocks, not a single string, because a reply can contain different kinds of things: text, a request to use a tool (Chapter 89), or, on models that think before answering, a thinking block before the text. Current models such as Opus 5.5 always think adaptively, so your code should pick out the blocks whose type is text rather than assume the first block is the answer. The official examples do exactly that.

Stop reasons

stop_reasonMeaningWhat to do
end_turnClaude finished naturallyUse the answer
max_tokensIt hit your max_tokens cap mid-answerThe answer is cut off: raise the limit or ask for less
stop_sequenceIt produced a stop sequence you definedExpected if you set one
tool_useClaude wants your program to run a toolRun it and send back the result (Chapter 89)
pause_turnA long-running server-side step pausedSend the response back to let it continue (Chapter 89)
refusalClaude declined for safety reasons; stop_details gives the categoryHandle gracefully in your app
model_context_window_exceededThe conversation filled the context windowShorten or summarise (Chapter 20)
Real-world example: a QA check

A common bug in apps built on the API: the code shows the reply to users without checking stop_reason, so answers that hit max_tokens appear silently truncated, ending mid-sentence. Add "a reply that hits max_tokens" to your test cases for any AI feature.

86.6The same call in Python and TypeScript

Writing raw HTTP is fine for learning, but real programs use Anthropic's official SDKs (software development kits). They add the headers for you, read ANTHROPIC_API_KEY automatically, retry temporary failures, and turn errors into clear exceptions. SDKs exist for Python, TypeScript, C#, Go, Java, PHP and Ruby. Verified 9 Nov 2026

Python: install (inside a virtual environment, Chapter 58)
python3 -m venv .venv && source .venv/bin/activate
pip install anthropic
Python: first_call.py
import anthropic

client = anthropic.Anthropic()          # reads ANTHROPIC_API_KEY from the environment

message = client.messages.create(
    model="claude-opus-5-5",
    max_tokens=1000,
    system="You are a senior QA engineer. Reply concisely.",
    messages=[
        {"role": "user", "content": "Give five boundary test values for an age field that accepts 18 to 65."}
    ],
)

for block in message.content:           # content is a list of blocks
    if block.type == "text":
        print(block.text)

print("Stop reason:", message.stop_reason)
print("Tokens in/out:", message.usage.input_tokens, message.usage.output_tokens)
TypeScript: install and first-call.ts
# npm init -y && npm pkg set type=module && npm install @anthropic-ai/sdk
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();          // reads ANTHROPIC_API_KEY

const message = await client.messages.create({
  model: "claude-opus-5-5",
  max_tokens: 1000,
  messages: [
    { role: "user", content: "Give five boundary test values for an age field that accepts 18 to 65." }
  ]
});

for (const block of message.content) {
  if (block.type === "text") console.log(block.text);
}
console.log("Tokens:", message.usage.input_tokens, message.usage.output_tokens);

Create a clientanthropic.Anthropic()new Anthropic()
Send a messageclient.messages.create(...)await client.messages.create({...})
Automatic retriesTwice by default, with backoff, for connection errors, 408, 409, 429 and 5xxSame behaviour
What the SDK does that curl doesn't
  • Headers and version are filled in for you, so you can't forget anthropic-version.
  • Retries with exponential backoff: by default the Python SDK retries certain failures twice (configurable with max_retries).
  • Typed errors: a 404 arrives as anthropic.NotFoundError, a 429 as anthropic.RateLimitError, so your code can handle each case properly instead of reading raw JSON.
  • Request IDs: message._request_id gives the ID to quote when reporting a problem to Anthropic support.
  • Streaming helpers: show the answer word by word as it's generated (Chapter 87).

86.7What a call costs

You pay per token: input tokens (everything you send, including the system prompt and earlier messages) and output tokens (everything Claude writes, including its internal thinking, which is billed as output even when you don't see all of it). Prices are quoted per million tokens (MTok). Verified 9 Nov 2026

ModelInput per MTokOutput per MTokGood for
Claude Fable 5.1$10$50The hardest reasoning and long agentic work
Claude Opus 5.5$4$20Recommended starting point for most work
Claude Sonnet 5.5$2$10Fast, strong everyday model
Claude Haiku 5.5$0.10 (prompts up to 100K tokens)$0.50High-volume, simple tasks

A worked example

You send a user story and instructions (about 500 input tokens) and get back test cases plus thinking (about 1,500 output tokens).

Cost arithmetic
Opus 5.5:   500 × $4 / 1,000,000   = $0.0020
          1,500 × $20 / 1,000,000  = $0.0300
                                     ────────
                         one call ≈ $0.032    → 1,000 stories ≈ $32

Haiku 5.5:  500 × $0.10 / 1,000,000 = $0.00005
          1,500 × $0.50 / 1,000,000 = $0.00075
                         one call ≈ $0.0008   → 1,000 stories ≈ $0.80

The real numbers are in each response's usage field, so you can measure instead of estimating. Batch processing is 50% cheaper, and prompt caching makes repeated long prompts much cheaper (Chapter 90).

Spend controls

Each usage tier has a monthly spend cap, and you can set your own lower limit on the Console's Billing page. When the tier cap is reached, requests return 429 until the next month or until a higher limit is approved. Set a limit before running anything in a loop.

86.8The Console playground

The playground (platform.claude.com/playground) lets you build a request with forms (model, system prompt, messages and every other parameter), run it, and see the response. It also shows the equivalent SDK code for each run, which you can copy into your program. It replaced the older Workbench, which closed on 17 August 2026. Use it to get a prompt right before you write code around it.

86.9When it goes wrong: error codes

Errors come back as JSON with a type, a message and a request ID:

{
  "type": "error",
  "error": { "type": "not_found_error", "message": "The requested resource could not be found." },
  "request_id": "req_011CSHoEeqs5C35K2UUqR7Fy"
}

Common misunderstandings
"My Claude Pro subscription covers API calls."
It doesn't. The API is billed separately, per token, through the Console.
"The first content block is always the answer."
Models that think may return a thinking block first. Select blocks with type == "text".
"max_tokens is how long the answer will be."
It's an upper limit. If it's too low, answers are cut off with stop_reason: "max_tokens".
"The API remembers my previous call."
It doesn't. Each request is independent: to continue a conversation you send all the earlier messages again (Chapter 87).
"Copying an old tutorial will work."
Old examples may set temperature or use retired model IDs, both of which now return errors. Check the current docs.

86.10Review

Key takeaways
  • API keys are created in the Claude Console (platform.claude.com) inside a workspace; API usage is billed per token, separately from chat plans.
  • Store the key in ANTHROPIC_API_KEY, never in code, chats or logs.
  • A request is POST https://api.anthropic.com/v1/messages with content-type, Authorization: Bearer … (or x-api-key) and anthropic-version: 2026-10-21, plus model, max_tokens and messages (and optionally system).
  • The response's content is a list of blocks; read the text blocks, check stop_reason, and use usage to track cost.
  • The Python (anthropic) and TypeScript (@anthropic-ai/sdk) SDKs handle headers, retries and typed errors.
  • Know the error codes: 400 request, 401 key, 403 permission, 429 limits, 500/529 Anthropic's side.
Check yourself

Which three body fields are required in every Messages API request?

system is optional, and temperature is no longer accepted on API version 2026-10-21.

Your script gets a 401 authentication_error. What's the most likely cause?

401 is about identity. Check that the environment variable is set in the terminal running the script.

A user reports that answers in your AI feature sometimes end mid-sentence. What should you check first?

Truncated answers come from hitting max_tokens. Raise the cap or handle that stop reason.

A call to Opus 5.5 uses 1,000 input tokens and 2,000 output tokens. Roughly what does it cost?

1,000 × $4 / 1M = $0.004, plus 2,000 × $20 / 1M = $0.04. Total $0.044.

Where should an API key used by a CI pipeline be stored?

Secrets stores keep keys out of code and logs and make rotation easy.
