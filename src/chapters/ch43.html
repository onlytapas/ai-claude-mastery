Claude's apps look like a simple chat window, but there are a few controls worth learning on day one. A conversation is a single thread of messages; Claude remembers everything inside it, but by default nothing from one conversation carries into another unless you switch on features such as memory or projects. Next to the send button is a model menu where you pick which Claude model answers and how hard it thinks. Higher settings give more thorough answers but take longer and use more of your allowance. Learn those controls, check your privacy settings once, and you are ready to work.

Screens change often

Every button name and menu location in this chapter was checked against Anthropic's help centre (support.claude.com) and claude.com on 9 November 2026. Anthropic changes the interface frequently, and it is currently rolling out a "new Claude experience" in stages, so your screen may not match exactly. If a control has moved, search the help centre for its name, or ask Claude itself: "Where is the setting for X in this app?"

43.1Getting an account

You can use Claude in a web browser at claude.ai, in the desktop app (macOS and Windows; Linux is in beta) or in the mobile app (iOS and Android). All of them use the same account and show the same conversation history, so you can start a chat on your laptop and carry on from your phone.

1. Go to claude.aior open the app
2. Choose a sign-in method"Continue with email" or "Continue with Google"
3. Confirm your emailopen the secure login link (or enter the code it gives you)
4. Confirm you are 18+and accept the terms
5. Start chattingon the Free plan, or upgrade later

A few practical details, from Anthropic's login help article:

  • Email login has no password. You get an email titled "Secure link to log in to Claude.ai". Open the link on the same device and you are logged in. Open it on a different device and it shows a verification code to type on the first one.
  • Use the same method every time. If you signed up with Google, log in with Google. Mixing methods is the most common reason people "lose" their chat history.
  • Email not arriving? Check your spam or junk folder for mail from @mail.anthropic.com.
  • Some people are asked to verify a phone number the first time they sign up or log in. If you see that message, follow the on-screen steps.
  • Work accounts are different. If your company has a Team or Enterprise plan, you are usually invited by an administrator and may log in through your company's single sign-on (SSO). Use that account for work data, not a personal one (Chapter 42).
Which plan do you need?

The Free plan is enough to learn everything in this chapter. As of 9 November 2026, Free gives "limited usage" with the Sonnet and Haiku models; paid plans (Pro, Max, Ultra, Team, Enterprise) add more usage, the Opus models and extra features such as Research and Claude Code. Prices and plan boundaries change, so check claude.com/pricing before you buy. Chapter 42 compares the plans in detail.

43.3Starting and managing conversations

Type your request in plain language and press Enter to send. Claude replies in the same thread. Everything you and Claude have said in that thread is sent to the model again with each new message, which is how it "remembers" the conversation. That shared text is the context window you met in Chapter 20.

When to start a new chat

One topic per conversation is a good rule. A new chat gives Claude a clean slate: no leftover assumptions from an earlier task, and fewer tokens to reread each time, which also saves usage. Stay in the same chat when the next request builds on what is already there, for example "now write the negative test cases for the same story".

Keep going in the same chat when…

you are refining one piece of work: improving a draft, asking follow-up questions about the same log file, or adjusting test cases you have just generated.

Start a new chat when…

the task changes, the conversation has become very long, Claude keeps repeating an earlier mistake, or you want an answer that isn't influenced by what came before.

Fixing a reply you don't like

  • Just say so. "That's too long. Give me five bullet points" works well. Anthropic's tutorial puts it simply: if a response is off, tell Claude and it will adjust.
  • Edit your own message. You can edit an earlier message and resend it, which creates a new branch of the conversation from that point. It is the cleanest way to fix a badly worded prompt without the bad answer staying in the context.
  • Retry. A retry control under Claude's reply asks for a fresh answer to the same message. Because language models are non-deterministic, the second answer will be worded differently and may be better.
  • Stop. While Claude is writing, the send button turns into a stop button. Use it the moment you can see the answer is heading in the wrong direction.

Finding, renaming and deleting chats

Claude names each new conversation automatically from its first messages. According to Anthropic's help article on deleting and renaming conversations, on the web each chat in the sidebar's chat history ("Chats and tasks" in the current layout) has a "⋮" menu with options such as rename and delete, and there is a "Select" option for deleting several at once. On iOS you press and hold a chat in the list; on Android you use the "⋮" menu at the top right of an open conversation. Many people also star important chats so they stay at the top of the sidebar.

Real-world example

Priya, a tester, keeps one long-running chat called "Sprint 42 test design". It works for two days, then answers start mixing up stories from earlier in the sprint. She asks Claude for a short summary of the decisions made so far, copies it into a new chat called "Sprint 42 test design (part 2)", and carries on. The new chat is faster, uses less of her allowance and stops confusing the stories.

43.4Choosing a model, effort and thinking

The model menu next to the send button controls three separate things. You can change any of them in the middle of a conversation; according to Anthropic's help article, "Changes apply starting with Claude's next response."

ControlWhat it changesPlain advice
ModelWhich Claude model answers. The menu shows the main current models, with older ones under "More models"Use the recommended current model for most work. Pick a faster, lighter model for quick, simple jobs. Fable is the most capable and the slowest (Chapter 40)
EffortHow thorough each response is: Low, Medium, High, Extra high, MaxEach model marks one level as "Default". Lower for routine tasks; higher for hard analysis

The help centre describes the effort levels like this: Low and Medium are for routine tasks and make your usage go further; High is "the best overall balance of quality and speed"; Extra high is for long-running coding and agentic tasks (Opus 4.7 and newer); Max is the most thorough. It also warns: "Higher effort means more thorough responses, but they take longer and use more tokens."

Under the hood: what "thinking" and "effort" actually do

When thinking is on, the model first writes reasoning tokens (its "scratchpad") before writing the answer you read. More tokens spent reasoning means more computation on your question, which tends to help with multi-step problems. That is the test-time compute idea from Chapter 19.

Current Claude models use adaptive thinking: the model decides for each message whether to think and how much. The effort level is the dial that nudges that decision. On easy questions the model may answer straight away even at high effort. That's why effort, not an on/off switch, is the main control on the newest models. Thinking tokens count towards your usage, which is why higher effort uses up your allowance faster.

43.6Incognito chats

An incognito chat is a conversation that is not saved to your chat history or to Claude's memory. According to Anthropic's help article (checked 9 November 2026):

  • How to start one: open a new chat outside a project and click the ghost icon at the top right. The chat gets a black border and an "Incognito chat" label. Click the "x" at the top right to end it.
  • What it doesn't do: it doesn't appear in your history, isn't added to memory, doesn't use your existing memory, isn't used for model training, and can't be reopened once closed.
  • What it still does: Claude can still see your profile preferences. Anthropic still keeps incognito chats for 30 days by default (longer on some Enterprise plans), and on Team and Enterprise plans they are included in data exports for account Owners.
  • Limits: not available inside projects. Under the new Claude experience, incognito chats open in the previous chat experience, so Claude can't create files or run code in them.
Incognito is not invisible
"Incognito means nobody can ever see it."
It means it isn't saved to your history or memory. Anthropic retains it for a period, and on business plans your organisation's owners may be able to export it. It is a tidiness and privacy tool, not a secrecy tool.

43.7Usage limits and making them last

Every plan has a usage limit: an allowance of work Claude will do for you before you have to wait. Anthropic's help centre describes two kinds: a five-hour session limit and weekly limits that apply across all models. Settings > Usage shows a "Current session" bar and when each limit resets. (Verified Ultra accounts don't have the five-hour limit; usage-based Enterprise plans are billed by consumption instead.) On paid plans you can switch on usage credits to keep going past your plan's limit.

The limit isn't counted in messages. It depends on how much work each message causes. Anthropic lists these as the things that use it up:

What uses moreWhy
Long messages and big attachmentsMore tokens for the model to read
Long conversationsThe whole thread is reread with each new message
Tools such as web search and ResearchEach search brings more text into the conversation
Stronger models and higher effortMore computation and more thinking tokens per answer
Artifacts, running code, creating files, browsingMulti-step work behind the scenes
Source: Anthropic help centre, "Usage limit best practices" (checked 9 November 2026).

Habits that stretch your allowance

  • Put everything in one well-structured message. The story, the acceptance criteria and the format you want, all at once, rather than drip-feeding them over five messages. (Chapter 44 shows how.)
  • Start fresh chats for new topics instead of continuing a huge thread.
  • Match model and effort to the task. Don't use Max to fix a typo.
  • Store reference documents in a project. Project content reused while it is still cached "counts less against your limits", in Anthropic's words; the cache expires after a period of inactivity.
  • Switch off web search when the answer should come only from your own documents.

43.8Keyboard and speed tips

Most people only need a handful of habits:

  • Enter sends; Shift+Enter adds a new line without sending, which is useful for multi-line prompts.
  • Paste screenshots directly into the message box instead of saving them first.
  • Drag files onto the chat window to attach them (Chapter 46 covers file types and limits).
  • The desktop app has a quick-entry shortcut you can customise in its settings, so you can call Claude up from anywhere on your computer (Chapter 51).
Shortcut lists change

Anthropic does not publish a stable shortcut list for the claude.ai web app in its help centre, and third-party lists disagree. The interface itself is the most reliable guide: look in the account menu for a keyboard shortcuts option. Common misunderstandings
"Claude remembers everything I've ever told it."
Inside one conversation, yes. Across conversations, only through features like memory or projects, and only what those features store.
"Always pick the biggest model and Max effort to get the best answer."
For simple tasks it's slower, uses up your allowance faster and often isn't better. Match the setting to the task.
"The usage limit is a fixed number of messages."
It depends on model, effort, conversation length, attachments and tools. One huge message with Research can use more than twenty short ones.
"Deleting a chat or using incognito erases all trace of it instantly."
Retention rules still apply. Read the privacy settings and your organisation's policy.
"Changing the model mid-chat restarts the conversation."
The new setting applies from the next reply, and the conversation so far is kept.

43.9Review

Key takeaways
  • The same account works on web, desktop and mobile. Log in with the same method every time.
  • One conversation is one context: Claude sees everything in the thread, nothing from other threads unless memory or projects bring it in.
  • Start new chats for new topics; edit, retry or simply give feedback to fix a poor answer.
  • The model menu next to the send button controls model, effort and thinking; changes apply from the next reply.
  • Check privacy settings on day one, and use incognito for chats you don't want in history or memory, remembering it is not secret.
  • Usage depends on how much work each message causes; one well-structured message beats many fragments.
  • Screens change: verify UI locations against support.claude.com.
